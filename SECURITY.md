# Politique de sécurité

## Versions prises en charge

Seule la **dernière version publiée** (voir les [releases](https://github.com/sauveteur71/carte-live-meshtastic/releases)) reçoit des correctifs de sécurité. Mettez à jour avant de signaler un problème afin de vérifier qu'il persiste.

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité (authentification, accès non prévu à une zone d'administration, injection, exposition de données, etc.), **ne l'ouvrez pas en issue publique**.

Signalez-la de préférence via l'onglet **Security → Report a vulnerability** de ce dépôt (avis de sécurité privé GitHub), ou via une [discussion privée](https://github.com/sauveteur71/carte-live-meshtastic/discussions) en indiquant clairement qu'il s'agit d'un sujet sensible, sans détailler publiquement la faille.

Merci d'indiquer :
- la version concernée et l'édition (France / internationale) ;
- les étapes pour reproduire ;
- l'impact potentiel (accès, données, disponibilité).

Le projet étant maintenu bénévolement, le délai de réponse n'est pas garanti, mais tout signalement sérieux sera traité en priorité.
